Shirkada Korontada ee SolarLight

Hadafkayagu waa inaan guri kasta keenno laydh jaban oo raqiis ah. Waxaan rabnaa inaan dadka ka caawinno inay helaan tamar la isku halleyn karo iyadoo la isticmaalayo awoodda qorraxda.

  • Adeegga ku xidhista iyo dayactirka
  • Solar yar oo guryaha loogu talagalay
  • Nalalka ku shaqeeya cadceedda
